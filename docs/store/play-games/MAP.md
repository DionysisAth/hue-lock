# Play Games icons: which file goes where

In Play Console: **Υπηρεσίες παιχνιδιών Play → Ρύθμιση και διαχείριση → Επιτεύγματα** (achievements) or **Βαθμολογικοί πίνακες** (leaderboards).
Open each entry by its name below, upload the matching file as its icon (512×512 PNG) and save. Play Games makes the grey "locked" version of achievement icons by itself.
